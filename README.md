# Dashboard de Cobranzas

Panel web estático para explorar cobranzas con filtros, tablas y gráficos.

## Qué incluye

- Resumen visual de registros cargados
- Filtros por supervisor, vendedor y provincia
- Tabla principal con columnas inmóviles
- Panel de registros sin match cuando existan
- Exportación CSV de los resultados filtrados

## Publicación

Este directorio contiene la versión lista para GitHub Pages.

## Nota

El uso de la aplicación depende de un archivo Excel de trabajo interno con el formato esperado por la organización.
